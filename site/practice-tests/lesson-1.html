Lesson 1 · Milk as a Molecular System

Three practice sets · 20 multiple-choice questions and 5 written-response questions in each set.

Directions: Each set has 20 selected-response questions. Choose one answer unless the question says Select all that apply. Then answer the five written questions in your own words. Open the feedback only after you finish. The multiple-choice score is out of 20; use the written-response key points as a self-check, not as an all-or-nothing grade.

Suggested use: Set 1 checks core ideas, Set 2 applies them to observations, and Set 3 mixes concepts. Try one set at a time without notes.
