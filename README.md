# Science Olympiad Food Science Study

A static study website for the Science Olympiad Food Science event. The site includes a ten-week study plan, self-contained lessons, lab notebook protocols and a practice question set.

## Preview locally

Open `site/index.html` in a browser.

## Deploy with Vercel

Import this GitHub repository into Vercel and set the project **Root Directory** to `site`. The site is plain HTML and CSS and does not need a build command.

## Sources

Course lessons summarize relevant material from Harold McGee's *On Food and Cooking* and link to the University of Guelph Dairy Science and Technology eBook, NIH Office of Dietary Supplements, FDA, USDA Agricultural Marketing Service, and the official Science Olympiad event page. The supplied book PDF is intentionally kept local and is not part of this repository.
